# Jalur Klip 3D `video-3d` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Model rendah bisa menambahkan klip 3D Blender ke video explainer short hanya dengan mengisi JSON dari katalog, dan semua kesalahan ditangkap `cek:3d`.

**Architecture:** Model menulis `<slug>.3d.json`. Node menggabungkannya dengan `katalog.json` dan waktu kata menjadi rencana jadi per klip, lalu Blender hanya membaca rencana jadi itu. Satu file Python per set, dan satu file aturan per kelompok kode validator.

**Tech Stack:** Node 22 (`node:test`, ESM), esbuild lewat `importTs`, sharp, ffmpeg/ffprobe, Blender 5.3 (`bpy`, Eevee), Remotion 4.0.539.

**Spec:** `docs/superpowers/specs/2026-11-18-video-3d-design.md`

## Global Constraints

- Semua pekerjaan di worktree `G:\Project\remotion-3d`, branch `feat/video-3d`. Folder `G:\Project\remotion` hanya dibaca, karena sesi lain sedang mengerjakan `jakarta-tenggelam` di sana.
- Jangan ubah skill `video-explainer`, aturan `cek:explainer` lama, atau engine sejarah.
- Blender opsional, tanpa maskot atau karakter, dan short 9:16 saja: `fps` 30, `lebar` 1080, `tinggi` 1920.
- Pesan validator berbentuk `lokasi: KODE masalah → PERBAIKI: langkah`. Selesai berarti 0 error dan 0 peringatan.
- Frame rencana berbasis 0 dan sama dengan frame lokal scene. Blender merender `0` sampai `frame_akhir - 1`.
- `scene` di `.3d.json` berbasis 1. Kunci `kata.json` berbasis 0 (`String(scene - 1)`).
- Nama klip: `scene-NN` dengan dua digit, file `public/klip/<slug>/scene-NN.mp4`.
- Test: `node --test "tests/3d/*.test.mjs"`. Render Remotion: set `$env:TEMP` dan `$env:TMP` ke `G:\Project\remotion-3d\out\tmp`.
- Setiap commit diakhiri baris `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Stage file satu per satu, jangan `git add -A`.

## Review Focus

1. `kata.json` dipotong ulang sehingga jumlah kata berbeda dari narasi: gerak tidak boleh diam-diam mulai di frame 8 (W1, Task 6).
2. File Python set diperbaiki setelah render: klip lama harus terbaca basi, walau akhir baris berubah karena checkout Windows (Task 4).
3. Gerak dipilih tapi tidak akan terlihat, misalnya `buka-jendela` dengan `awal: terbuka` (C6, Task 5).
4. Render terhenti di klip kedua: klip pertama tetap tercatat, MP4 lama klip kedua utuh, dan render ulang melanjutkan (Task 9).
5. `di` ditulis dengan huruf besar, frasa dua kata, atau kata bertanda `*...*` dan tanda baca (Task 3).
